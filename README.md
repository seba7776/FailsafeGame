# Failsafe

FPV drone game for Windows (first playtest build).

**Download one of these** (tap the file, then the download button):

- **Failsafe-Setup.exe**: the installer. Installs the game with a desktop shortcut; starts fast. Recommended.
- **Failsafe.exe**: one file, no install. Takes about 20 seconds to start each time.

Windows may warn that the app is from an unknown publisher (it isn't code-signed). Click "More info" → "Run anyway".

Found a bug or have an idea? Open the laptop in the garage and use the **Feedback** app.
