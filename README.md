# Failsafe

FPV drone game for Windows (playtest build, 25 Oct 2026: fixes the cutscene click freeze, the black shapes while flying, and the freeze when walking out of the garage).

**Download [Failsafe-Setup.exe](https://github.com/seba7776/FailsafeGame/raw/main/Failsafe-Setup.exe)**, run it, and start Failsafe from the desktop shortcut.

Windows may warn that the app is from an unknown publisher (it isn't code-signed). Click "More info" → "Run anyway".

The first time you walk out of the garage it shows "STEPPING OUT" for a few seconds while it prepares the village; that's normal.

Found a bug or have an idea? Open the laptop in the garage and use the **Feedback** app.
